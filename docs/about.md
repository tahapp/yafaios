YafaiOS is a personal engineering notebook by Taha, an iOS developer. It documents Swift, UIKit, Core Animation, Core Graphics, and Apple's development frameworks.

The focus is on concise technical observations: how something works, the rule to remember, and the code that makes it concrete. Some notes are experiments; others grow into deeper explanations.
